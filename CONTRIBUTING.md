# Contributing to MOIST

Thank you for your interest in contributing to MOIST! We're excited to collaborate with you.

Before you start, please familiarize yourself with the following guidelines. Following these guidelines helps to communicate that you respect the time of the developers managing and developing this open source project. In return, they should reciprocate that respect in addressing your issue, assessing changes, and helping you finalize your pull requests.

There are many ways to contribute, from writing tutorials or blog posts, improving the documentation, submitting bug reports and feature requests or writing code which can be incorporated into

After submitting a pull request, you will be asked in the PR thread to sign a [CLA](CLA.md) with your GitHub account. Please note that this CLA is an **interim agreement**: it is in place until the licensing of MOIST within established quantum-chemistry packages has been settled. Once those discussions conclude, the CLA will be retired and no CLA will be required for future contributions; licenses already granted under it remain in effect.
